[既有 6 轴验证记录](experiments/joint_reverse_suffix_20261029/verification.json) 只对应历史实现与运行。本次不沿用历史测试数量声称新的软件或算法质量。

## 2. 迁移与共同契约

| 验证对象 | 必须检查的行为 |
| --- | --- |
| 6 轴兼容 | 原冻结输入、候选和模板回放，边界、路径、代价、b1 双初始化验收及逐帧标签一致。 |
| 包独立运行 | 正式包安装后可从仓库外启动；DTW 源码及依赖齐全，不导入实验、旧库或历史运行源码。 |
| 共用实现 | 两份配置使用相同特征/模板/评分/搜索实现；无按机器人切换阶段数或搜索器的分支。 |
| 布局与模板 | 14/16 维、关节次序、夹爪列、特征与模板摘要匹配；非法或错配输入在评分前失败。 |
| 时间对齐 | 原帧/时间单调、每帧状态可追溯；7 轴最近样本选择、等距规则、容差与误差记录正确。 |
| 候选 | 任意一爪即可；不伪造初始/闭合事件，末帧不作边界；身份与原帧严格一致。 |
| 搜索 | S5→S2 最优两条后缀、DTW 完整端点、冻结拒绝阈值、缺失不补位；保留支持的最长后缀。 |
| 输出 | b 属于前段；五段/四段数组按各自所需边界判断完整性，缺失为 -1，JSON 保留可用边界。 |
| 数据保护 | 原始输入、训练运行、历史结果、人工记录不被覆盖；配置变化用新运行。 |
| VLM 移除 | 正式主 CLI 无 VLM 命令、provider、凭据需求或自动回退；保留 joint 所需共享能力。 |

默认离线测试只保留当前 joint 流程及共享检测器的检查；VLM 专项已随实现移除。软件检查不能作为 joint 边界质量依据。

## 3. 10 条示范与独立评估

示范验证检查 10 条不同轨迹的来源、选取/替换理由、候选覆盖、Codex 逐边界依据、模板来源与冻结摘要。无法确认或没有候选的边界保持未确认，不因模板建立需要而补造。

训练回放只检查实现与参考拟合情况，不是泛化评估。独立评估必须使用与示范不重叠的清单，在模板冻结后执行，参考答案不得进入推断或参数选择。评价指标、误差容差与分母应在该次评估前声明；没有独立参考时不报告准确率。

程序完整率、边界正确性、Codex 观察和用户确认分别记录。拒绝阈值是探索性规则，不是正确概率；S5 覆盖末尾不代表放置成功。
